### 주요 기능

- 게임 정보 모드와 탐색 전용 모드 지원
- 함대, 원정, 입거, 건조 및 임무 정보 제공
- 전투 보조 기능 및 로컬 전투 로그 제공
- 스마트폰, 태블릿 및 폴더블 기기 화면에 대응
- 중국어 간체, 중국어 번체 및 일본어 지원
