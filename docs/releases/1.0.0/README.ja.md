### 主な機能

- ゲーム情報モードとブラウズ専用モードに対応
- 艦隊、遠征、入渠、建造、任務の情報を表示
- 戦闘支援機能とローカル戦闘ログを提供
- スマートフォン、タブレット、折りたたみ端末に対応
- 簡体字中国語、繁体字中国語、日本語に対応

下の APK をダウンロードしてインストールしてください。初回インストール時は、ブラウザーによる提供元不明のアプリのインストールを許可する必要があります。
