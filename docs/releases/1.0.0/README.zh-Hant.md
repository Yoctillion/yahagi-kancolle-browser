### 主要功能

- 支援遊戲資訊模式與純瀏覽模式
- 提供艦隊、遠征、入渠、建造和任務資訊
- 提供戰鬥輔助與本機戰鬥日誌
- 適配手機、平板和摺疊螢幕
- 支援簡體中文、繁體中文和日語
