### 主要功能

- 支持游戏信息模式与纯浏览模式
- 提供舰队、远征、入渠、建造和任务信息
- 提供战斗辅助与本地战斗日志
- 适配手机、平板和折叠屏
- 支持简体中文、繁体中文和日语
