# 公共魔改库

魔改页面的“魔改资源文件夹”用于保存可自行编辑的资源和最近应用的搭配。首次使用选择本机 Documents（文档）根目录并授权，应用会自动建立 `Documents/Yahagi/Mods`；也可以选择 Documents 下自己建好的独立文件夹。

旧版默认中文目录会在有父目录授权且 `Mods` 尚不存在时整体更名，资源、包标记、备份及配置保持原样。若英文目录已存在或授权不足，保留旧目录并显示操作提示，不覆盖目标或合并文件。自行选择的其他目录不会自动改名。

## 导入与更新

- **导入魔改包**：选择 ZIP，确认后将资源按游戏路径解压保存到魔改资源文件夹，同时建立私有运行副本。原 ZIP 留在原位置，不会复制或移动到魔改库。
- **手动放入**：将 ZIP 或已解压的包文件夹复制到魔改资源文件夹，然后点击“扫描文件夹”，检查新增、更新、重复或无效提示，再确认导入。成功后清理库内已导入的 ZIP，仅保留解压目录；预览、取消、无效文件和导入失败时保留 ZIP。清理失败会提示，可再次扫描确认重试。
- **自行修改**：在包目录内修改图片、音频或坐标文件，再扫描。保留 `.yahagi-package.json`，这样应用才能识别同一个包并保留原开关和优先级。

新增包默认关闭。更新保留仍存在资源的选择，新加资源默认不选。扫描确认只改变待应用配置；点击“应用并刷新游戏”后才替换当前生效版本。取消更新会继续使用旧运行副本，公共文件夹里的手动修改仍保留，可再次扫描。

已成功导入的 ZIP 会清理；被跳过的重复 ZIP 和无效 ZIP 会保留。清理后重新放入同名但内容不同的 `cache.zip` 会作为新包导入，不会仅凭文件名覆盖旧包。更新已有包时，请修改对应解压目录并保留包标记。

导出到公共库的坐标会合并成标准 JSON，WAV 保留正确的 `.wav` 扩展名。不要修改库根目录的 `library.json`、备份文件和包标记文件。

## 删除与恢复

单包删除和“删除全部魔改”均先标红待处理，底部“取消”可以撤销。应用成功后才删除包的公共副本和私有副本；库外自行保存的原 ZIP 不受影响。若公共文件删除失败，会保留待清理记录并显示提示，再次扫描可重试。

公共库位于用户文档中，安装新版本和卸载应用都会保留这个文件夹。重新安装后需要重新授权同一个文件夹，扫描并确认恢复最近一次成功应用的开关、资源选择和包优先级，最后点击“应用并刷新游戏”。应用卸载前尚未成功备份的修改无法从旧备份恢复。

文件夹授权丢失或不可用时，已经保存的私有运行资源仍可读取；请重新选择同一个文件夹后再应用新配置。扫描缺失或损坏的包不会删除当前运行副本。
