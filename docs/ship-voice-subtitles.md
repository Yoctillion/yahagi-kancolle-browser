# 舰娘语音字幕

在“设置 → 画面与声音”中开启“舰娘语音字幕”。此功能默认关闭；开启后可以通过下拉菜单选择小、中、大三档字号，以及简体中文、繁體中文、日本語、English、한국어 五种字幕语言。默认中号、简体中文。字幕语言独立于应用界面语言，选择后会保存；切换应用界面语言不会自动更改字幕语言。

字幕采用电影字幕样式，初始位于游戏画面底部居中。字幕文字可以穿透点击。顶部功能菜单的界面锁定关闭时，字幕上方显示独立拖动手柄，通过手柄可以移动字幕；锁定后隐藏手柄，位置固定。位置按游戏画面的相对坐标保存，重新打开功能及调整窗口后继续使用。

长台词会根据语音时长分成最多两行的字幕逐页显示，避免大字号文字超出游戏画面。

设置的“数据更新”区域保留一个检查更新按钮，下面用两行相同格式展示资料版本和最近检查时间：第一行对应简中、繁中和日文台词资料组，第二行对应英韩台词与简中、繁中、英文、韩文舰名、改装词缀、装备名和类别资料包。界面不显示来源标签或当前字幕语言。每次手动检查覆盖全部这些文件，与当前选择的字幕语言和应用界面语言无关。

资料均有内置快照及离线缓存。每组完整校验并保存后才生效；某组更新失败时继续使用该组已有资料，另一组可以独立更新成功。只有开启字幕时才进行自动检查，各组每 24 小时最多自动尝试一次，失败也计入间隔；手动检查可以再次尝试。此处下载的是字幕、舰名、装备名和类别文本，不包含游戏 MP3 文件。

切换语言时会清除当前字幕，等所选语言的资料准备好后再显示后续播放的台词。较早语言的下载即使稍后完成，也不会覆盖当前语言的字幕或版本信息。

字幕监听游戏播放器的播放事件。预加载音频不会显示字幕，缓存中的音频再次播放时仍会显示；停止、暂停、播放失败、离开页面或关闭功能时会清除相应字幕。没有匹配译文的台词会跳过。游戏内彻底关闭语音、导致游戏不创建播放器时，没有播放事件可供识别。

字幕按原始游戏资源路径及当前舰娘编号匹配。魔改包替换了同一路径的音频内容时，字幕仍对应原版台词。

英韩资料包含 KC3 的基础台词，并为改装舰继承未单独改写的台词。当前尚未接入 KC3 按音频文件大小识别季节、活动等变体的规则，这些语音可能显示基础台词。

播放器就绪后的字幕监听采用事件触发，稳定空闲时没有每秒轮询；后台暂停字幕观察和自动检查。拖动与换页复用分页结果，只有台词、字号或有效宽度改变时才重新测量文字。无新版本的检查只保存小型检查记录。

说话者舰名跟随字幕语言：简中、繁中、英文、韩文使用 KC3 的舰名和改装前后缀资料，日文保留游戏原名。优先使用上游按舰娘编号指定的名称，以区分宗谷等同名不同形态；再查完整舰名，最后用前后缀匹配已知基础舰名。缺少译名时保留完整原名。切换语言或更新舰名资料后，会重新发送名称映射，无需重新载入游戏主数据。应用其他功能的舰名不受此设置影响。

应用界面另外使用自己的语言设置：英文、韩文显示相应舰名、舰种、装备名和装备种类，简中、繁中、日文沿用已有显示。这个转换只用于显示，不改写游戏主数据或历史日志。旧日志中保存的简／繁中文译名在没有歧义时反查目标语言，未知名称保留原文；游戏画面保持原样。

## 来源

简中、繁中和日文来自 [kcwiki 字幕接口](https://acc.kcwiki.cn/subtitles/zh-cn)，英韩台词及四语舰名、改装词缀、装备名、类别来自 [KC3 翻译库](https://github.com/KC3Kai/kc3-translations)。语音编号映射参考 [poi-plugin-subtitle](https://github.com/kcwikizh/poi-plugin-subtitle)。KC3 资料包中的全部 22 份文件固定到同一个仓库提交；版本采用该提交的 UTC 时间。旧 schema 1／2 缓存缺少完整语言或装备、类别资料，会自动回退完整内置包，即使提交 SHA 相同也不会跳过。具体快照、署名与许可信息见 [字幕资料说明](../assets/data/subtitles/SOURCES_AND_LICENSES.md) 和项目 `THIRD_PARTY_NOTICES`。
