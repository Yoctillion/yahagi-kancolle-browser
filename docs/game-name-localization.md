# 应用内游戏名称翻译

应用界面语言为英文或韩文时，游戏画面以外的舰娘名、舰种、装备名和装备种类使用相应译名。简体中文、繁体中文和日文继续沿用现有显示方式，包括开发计算器既有的中文译名。语音字幕仍由单独的字幕语言设置控制。

## 资料与更新

设置的数据更新区域统一显示“翻译资料”，保留一个检查更新按钮和两行版本、检查时间。第一行对应 kcwiki 的简中、繁中、日文台词；第二行对应固定同一仓库提交的 KC3 资料包：英韩台词、四语舰名与改装词缀、四语装备名、舰种和装备种类，共 22 份 KC3 源文件。未变化的资料沿用缓存，完整校验和保存成功后才采用新资料；一组失败继续保留该组原有资料。

内置快照与缓存提供离线使用。旧版不完整的 KC3 缓存不能覆盖新版完整快照。日文名称取游戏原名，无需另建日文译名表。来源、固定提交与许可见 [资料说明](../assets/data/subtitles/SOURCES_AND_LICENSES.md)。

## 覆盖入口

- 舰队概要和详情、所有显示密度、改造目标、建造和修理、泊地修理、野埼、出击检查。
- 持有及未持有舰娘、装备仓库、装备使用归属、舰种和装备类型、双向装备兼容抽屉及筛选。
- 战前敌舰预览和提示、实时战斗、战斗详情及回放、掉落、重伤名单。
- 建造、开发、退役和战斗日志，以及筛选选项和旧记录的显示。
- 开发、改修、经验计算和选择器、海域敌舰详情、配装预览与有结构快照的历史配装。
- 远征条件中的实体名称、任务标题、说明、条件、步骤和奖励中的已知名称、置顶任务及任务完成提示。
- 新舰弹窗、开发结果提示、定时通知和常驻任务中的舰娘名称。
- 顶部资源筛选和编辑中的间宫、伊良湖及材料名称；仓库、兼容抽屉和改修中的鱼雷／特殊潜航艇分类。

搜索同时接受原名与译名，名称排序按显示译名处理，舰娘编号可以区分宗谷、Glorious 等同原名不同形态。名称作用域位于导航器外，语言或资料变化也会刷新弹窗和抽屉。

名称匹配按首字符分组并按需生成索引，重复舰名和复合字段使用有界缓存。简繁日不建立翻译索引，资料检查状态也不会额外刷新名称控件或通知。

## 数据边界

翻译只发生在显示端；游戏主数据、数据库历史记录、战斗身份匹配、机制计算、资源路径和面向其他工具的 JSON 导出仍保留原始值。用户自定义舰队名、基地名和记录名称不做替换。历史简繁中文实体名只在能够唯一映射时转译，缺少或有歧义的条目回退原文。

图片素材内的文字不由文本词典修改。仅保存为 PNG、没有结构快照的早期历史配装图片会保留原图文字；有结构快照的记录按当前语言重新绘制。上游尚未提供的译名继续使用原名。
